魚釣りの好きな人のことを、日本では「太公望」と呼ぶ。この言葉のもとになったのは、約3000年前の中国の人物である。

殷の西方、渭水という川のほとりで、白髪の老人が釣り糸を垂れていた。狩りに出た周の君主・西伯（のちの文王）は、この老人と語り合ううちに、その知恵に驚き、「わが祖父の太公が待ち望んでいた人物こそ、あなたに違いない」と言って、車に乗せて連れ帰った。この老人、呂尚は「太公望」と呼ばれ、文王とその子の武王を助けて、殷を倒す大事業に力を尽くしたという【伝承】。

この回では、殷に代わって中国を支配した==[[周]]==の王朝と、その支配のしくみである==封建制==を見ていこう。

## 周の興起

周は、黄河の支流・渭水の流域（現在の陝西省）に興った部族である。伝説では、農業の神・后稷を祖先とし、もとは殷に従う西方の勢力だった。文王（西伯昌）の時代に周辺の国々を従えて力をつけ、その子の==武王==のとき、殷を攻めた。

前11世紀半ば、武王は、黄河の渡し場の孟津に諸侯を集め、黄河を渡って殷の都に迫った。そして、都の南の牧野で殷の紂王の軍と戦った。

@battle muye phase=0
『史記』によれば、殷の兵士たちは紂王のために戦う気がなく、前列の兵は戈を逆さにして周の軍を迎え入れた。殷軍はたちまち崩れ、紂王は鹿台に登って火に飛び込んで死んだという。これが==牧野の戦い==である。

@battle muye phase=3
:::topic source | 「甲子の朝」――青銅器が証明した戦いの日
1976年、陝西省臨潼で、一つの青銅器が見つかった。器の内側に鋳込まれた銘文は、こう始まっている。

>> 武王、商を征す。唯れ甲子の朝なり。歳（木星）鼎（ただ）しくして、克く昏夙（一夜のうちに）商を有（たも）つ。
-- 出典：利簋銘文（中国国家博物館所蔵、本サイト読み下し・意訳）

『尚書』や『史記』は、牧野の戦いが「甲子の日の朝」だったと伝えていた。この器は、戦いの8日後に、武王から褒美を受けた利という人物が作らせたもので、文献の記述が事実だったことを、同時代の史料によって裏づけるものとなった。木星の位置についての記述は、戦いの年代を推定する手がかりにもなっている。夏商周断代工程は、この戦いを前1046年としたが、年代については諸説がある。
:::

:::topic source | 「書を尽く信ずれば」――孟子の疑い
『尚書』の一篇（武成篇）は、牧野の戦いのすさまじさを「血流れて杵を漂わす」（流れた血で、臼をつく杵が浮かんで流れた）と描いていた。これに対して、戦国時代の儒家・孟子は、次のように言った。

>> 書（『尚書』）をことごとく信じるのなら、書などない方がましだ。私は武成篇のうち、二、三の文を取るだけである。仁の人には天下に敵がいない。最も仁なる者（武王）が、最も不仁なる者（紂王）を討ったのに、どうして血が流れて杵を漂わすようなことがあろうか。
-- 出典：『孟子』尽心下篇（本サイト訳）

孟子が疑った理由は、「仁者の戦いでそんなに人が死ぬはずがない」という道徳的なものだった。歴史史料の記述を鵜呑みにしないという姿勢は、2000年以上前にもあったのである。
:::

## 周の支配――封建制

殷を倒した周は、渭水流域の==鎬京==（現在の西安の近く）を都とした。武王が亡くなったあとは、武王の弟の==周公旦==が、幼い成王を助けて政治を行った。周公旦は、殷の遺民たちの反乱（三監の乱）を鎮め、東方を治めるための拠点として、黄河中流の==洛邑==（現在の洛陽）を築いた。のちに孔子は、周公旦を理想の政治家として深く敬った。

周の王は、広い支配地をどのように治めたのだろうか。王は、都の周りの土地（王畿）を直接治め、その外側の各地には、一族や功臣、そして古くからの有力な氏族の長を==諸侯==として送り込み、それぞれに土地（封土）と人民を与えて治めさせた。諸侯は、自分の領地の中で、さらに家臣の==卿・大夫・士==に土地（采邑）を与えた。その代わりに、諸侯は王に貢ぎ物を納め、戦争のときには兵を率いて従軍する義務を負った。このしくみを==封建制==という。「封建」とは、「土地を封じて（境界を定めて）国を建てさせる」という意味である。

### 宗法――一族の決まり

周の封建制の土台となったのが、==宗法==と呼ばれる一族の決まりである。一族の本家（大宗）は、正妻が産んだ長男（嫡長子）が代々受け継ぎ、ほかの子どもたちは分家（小宗）をつくって本家に従う。一族の者は、本家の長のもとで共通の祖先を祭り、そのつながりを確かめ合った。

周王の一族は姫姓であり、各地に封じられた同姓の諸侯は、周王を本家とする分家にあたる。異姓の諸侯とも、婚姻によって親族の関係を結んだ。周の封建制は、血縁と祖先祭祀によって結びついた、一つの大きな「家」のような秩序だったのである。

:::topic confuse | 周の封建制と、ヨーロッパの封建制
「封建制」という同じ言葉が、中国の周と、中世ヨーロッパの両方に使われるので、混同しやすい。中身はかなり違う。

| | 周の封建制 | 中世ヨーロッパの封建制 |
|---|---|---|
| 時代 | 前11〜前8世紀ごろ（西周） | 9〜13世紀ごろ |
| 結びつきの基盤 | ==血縁==（==宗法==）。一族を各地に封じる | ==契約==。主君と家臣の個人的な取り決め |
| 関係の性格 | 本家と分家の上下関係 | ==双務的==（主君も家臣を保護する義務を負う） |
| 複数の主君 | 考えにくい | 一人の家臣が複数の主君に仕えることもあった |
| 土地 | 封土・采邑 | 封土（レーン） |
| 支配の対象 | 土地と人民 | 土地と農奴（荘園制と結びつく） |

日本語の「封建制」は、もともと周の制度を指す言葉だった。明治時代に、ヨーロッパの「フューダリズム」の訳語としても使われるようになったため、二つの意味が混在することになった。
:::

:::topic trivia | 「中国」という言葉の最古の例
1963年、陝西省宝鶏で、農家の裏の崖から一つの青銅器（何尊）が見つかった。この器の内底には、周の成王の時代に、洛邑の建設について記した122字の銘文が鋳込まれていた。その中に、武王の言葉として、次の一文がある。

>> 余（われ）其れ茲（こ）の中国に宅（お）り、自（よ）りて民を乂（おさ）めん。
-- 出典：何尊銘文（宝鶏青銅器博物院所蔵、本サイト読み下し）

ここでいう「中国」は、国の名前ではなく、「天下の中心の地域」、つまり洛邑のあたりを指している。それでも、これが「中国」という言葉が文字に記された最も古い例とされる。この何尊は、一時は廃品として売られかけ、博物館の職員が見つけて買い戻したものだったという。
:::

## 天命と易姓革命

周は、殷に代わって王となったことを、どのように正当化したのだろうか。周の人々が持ち出したのが、==天命==の考え方である。

天下を治める王は、天の命令（天命）を受けて、天の子（==天子==）として地上を治める。しかし天命は永遠のものではない。王が徳を失い、民を苦しめれば、天は天命を改め、徳のある別の者に与える。殷の紂王が天命を失い、徳のある周の文王・武王が新たに天命を受けたのだ――と、周の人々は説明した。

天命が改まって（革命）、王の家の姓が易わる（易姓）ことを==易姓革命==という。のちの儒家は、易姓革命の方法を二つに分けて説明した。

:::topic confuse | 禅譲と放伐
| 方法 | 内容 | 伝説上の例 |
|---|---|---|
| ==禅譲== | 天子が、徳のある人物に平和的に位を譲る | 堯 → 舜 → 禹 |
| ==放伐== | 徳を失った君主を、武力で討って追放する | 殷の湯王が夏の桀王を討つ、周の武王が殷の紂王を討つ |

のちの時代には、武力で実権を握った者が、形のうえだけ前の皇帝から位を譲られる「禅譲」の形式をとることが多くなった。たとえば、後漢から魏への交代（220年）や、隋から唐への交代（618年）である。

なお、「革命」という言葉は、明治時代の日本で、英語の「レボリューション」の訳語にも使われた。もともとは「天命が改まる」ことを意味する言葉だったのである。
:::

:::topic source | 周公の戒め――「殷を鑑とせよ」
天命が失われうるという考えは、王にとって脅しでもあった。周の初めの王たちは、殷が滅んだ理由を、酒におぼれて政治を怠ったことにあると考え、自らを強く戒めた。周の康王の時代の青銅器「大盂鼎」の銘文には、王の次のような言葉が記されている。

>> 私は聞いている。殷が天命を失ったのは、殷の辺境の諸侯から朝廷の官吏に至るまで、みな酒にふけったからである。それで軍を失ったのだ。
-- 出典：大盂鼎銘文（中国国家博物館所蔵、本サイト意訳）

『詩経』にも「殷の鑑（かがみ）遠からず」という言葉がある。殷が戒めとすべき手本は、遠くにあるのではなく、すぐ前の夏の滅亡にある――転じて、失敗の手本はすぐ身近にある、という意味で使われる。
:::

## 西周の衰え

周の初めの約100年は、王の力が強く、安定した時代だった。しかし、代が重なるにつれて、王と諸侯の血縁のつながりは薄れ、諸侯は自立の傾向を強めていった。周辺の異民族の侵入にも悩まされるようになった。

前9世紀半ばには、暴政を行った厲王が国人（都の住民）の反乱によって追放され、王のいない時代が14年間続いた（共和の政治）。中国の歴史で、年代を正確にたどれるのは、このときの前841年からである。

:::topic myth | 笑わない后と烽火
西周の最後の王・幽王には、褒姒という美しい后がいた。しかし、褒姒はまったく笑わなかった。あるとき、幽王が敵の襲来を知らせる烽火（のろし）を上げさせると、諸侯たちがあわてて駆けつけたが、敵はいない。その間の抜けた様子を見て、褒姒は初めて笑った。喜んだ幽王は、その後も何度も烽火を上げさせたので、諸侯は信用しなくなった。そして、本当に犬戎が攻めてきたとき、烽火を上げても、もう誰も来なかった――。【伝承】

『史記』に記されたこの話は、「オオカミ少年」に似た教訓話として有名である。しかし、西周の時代に烽火による通信網があったという証拠はなく、話は後世に作られたものと考えられている。2010年代に公表された戦国時代の竹簡（清華簡『繋年』）は、幽王が太子を廃して褒姒の子を立てようとしたため、太子の母の実家の申が、犬戎と結んで攻めてきたと記しており、烽火の話は出てこない【諸説】。
:::

前771年、異民族の==犬戎==が都の鎬京を攻め、幽王は殺された。翌前770年、幽王の子の==平王==は、都を東の==洛邑==に移した。これ以前を==西周==、これ以後を==東周==と呼ぶ。東周の時代、周王の権威は衰え、各地の諸侯が実力で争う==春秋・戦国時代==が始まる（第3部）。

:::summary
- 前11世紀半ば、渭水流域に興った==周==の==武王==が、==牧野の戦い==で殷を倒した。都は==鎬京==。
- 周公旦が成王を補佐して周の支配を固め、東方の拠点==洛邑==を築いた。
- 周は、一族・功臣を==諸侯==として各地に封じ、封土を与えて貢納と軍役を課す==封建制==を行った。諸侯の下には==卿・大夫・士==がいた。
- 封建制は、嫡長子が本家を継ぐ一族の決まりである==宗法==によって支えられた。血縁にもとづく点が、契約にもとづく中世ヨーロッパの封建制と異なる。
- 王は==天命==を受けた==天子==とされた。天命が改まって王朝が交代することを==易姓革命==といい、==禅譲==と==放伐==の二つの形がある。
- 前771年、==犬戎==の侵入で鎬京が陥落し、前770年に都を洛邑に移した（==東周==の始まり）。
:::
