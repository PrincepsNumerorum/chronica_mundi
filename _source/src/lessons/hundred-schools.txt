「矛盾」「五十歩百歩」「助長」「朝三暮四」「蛇足」――私たちが毎日のように使うこれらの言葉は、どれも2300年以上前の中国の思想家たちの書物に由来している。

春秋・戦国時代の争乱の中で、諸侯たちは、国を強くするための知恵を求めて、身分を問わず、才能のある人材を集めた。こうした中で、多くの思想家が現れ、それぞれの考えを説いて諸国を渡り歩いた。彼らを、「子」（先生）と呼ばれる多くの思想家たち、多くの学派という意味で、「==諸子百家==」という。

## 諸子百家の登場

戦国時代の諸国の君主は、富国強兵のための政策や、他国との外交の策を、思想家たちに求めた。思想家たちの多くは、「==士==」と呼ばれる、貴族の最下層や、学問によって身を立てようとする人々の出身であった。彼らは、自分の考えを採用してくれる君主を求めて、各地を旅した。

とくに、東方の大国==斉==の都==臨淄==では、前4世紀、王が城門の一つ稷門（しょくもん）の近くに屋敷を構えて、各地の学者を招き、手厚く待遇した。ここに集まった学者たちを「稷下（しょくか）の学士」といい、さまざまな学派の学者が、自由に議論を戦わせた。

## 儒家

### 孔子

==儒家==の祖は、春秋時代の末に、魯の国に生まれた==孔子==（前551ごろ〜前479年）である。孔子は、周の初めの社会を理想とし、周の時代に整えられた礼（社会の秩序を保つための儀礼や規範）を回復することで、乱れた世の中を立て直そうとした。

孔子は、人を思いやり、愛する心である「==仁==」を、最も大切な徳とした。そして、仁の心が、親や兄など身近な人への愛（孝・悌）から始まり、外に向かって形となって表れたものが「==礼==」であると考えた。孔子は、為政者が、まず自らの徳を修めて、民衆を徳によって導くべきであると説いた（==徳治主義==）。

!image file="Confucius Tang Dynasty.jpg" cap="孔子像。唐の画家呉道玄（呉道子）の作と伝えられる絵を、後世に石に刻んだものの拓本。"

孔子は、自分の理想を実現しようと、弟子たちを連れて10年以上も諸国を巡ったが、用いられることはなかった。晩年は魯に戻って、弟子の教育と古典の整理に努めた。孔子の言葉や、弟子との問答は、弟子たちによって『==論語==』にまとめられた。

:::topic source | 『論語』のことば
>> 先生（孔子）は言われた。「法令で民を導き、刑罰で民を統制すれば、民は刑罰をうまく免れようとして、恥を感じなくなる。徳で民を導き、礼で民を統制すれば、民は恥を知り、自ら正しくなる」。
-- 出典：『論語』為政篇（本サイト訳）

>> 子貢が尋ねた。「一言で、一生行い続けるべきことはありますか」。先生は言われた。「それは恕（じょ、思いやり）だろうか。自分がしてほしくないことは、人にしてはならない」。
-- 出典：『論語』衛霊公篇（本サイト訳）

最初の言葉は、法と刑罰によって国を治める法家の考え方と、徳と礼によって国を治める儒家の考え方の違いを、最もよく示している。
:::

!image file="20230612 Dacheng Dian, Qufu Kongmiao.jpg" cap="曲阜（山東省）の孔子廟の大成殿。孔子の死後、その旧宅に建てられた廟が、歴代の王朝によって拡張された。現在の建物は18世紀初めの再建。"

### 孟子と荀子

戦国時代には、孔子の教えを受け継いで、二人の重要な思想家が現れた。

==孟子==（前372ごろ〜前289年ごろ）は、人間の本性はもともと善であるとする「==性善説==」を説いた。そして、力によって支配する「覇道」を退け、徳によって民衆を治める「王道」を説いた。さらに、民衆の支持を失った暴君は、天命を失ったのであり、これを討つことは許されるとして、==易姓革命==を正当化した。

:::topic source | 孟子の性善説
>> 人が、幼い子どもが今にも井戸に落ちそうなのを見たとする。だれでも、はっとして、かわいそうに思う心が起こる。それは、その子の親と親しくなろうとするからでも、村人や友人にほめられたいからでも、見捨てたと悪く言われるのが嫌だからでもない。……かわいそうに思う心がない者は人間ではない。……かわいそうに思う心は、仁の芽生えである。
-- 出典：『孟子』公孫丑上篇（本サイト訳・抄訳）

人にはだれでも、仁・義・礼・智の4つの徳の「芽生え」（四端）が備わっている。それを育てていけば、だれでも善い人間になれる、と孟子は考えた。
:::

これに対して、==荀子==（前298ごろ〜前238年ごろ）は、人間の本性は、放っておけば利益を求めて争う悪いものであるとする「==性悪説==」を説いた。そして、外から「礼」によって人の性質を正していくことが必要だとした（礼治主義）。「人の本性は悪であり、その善なるものは人為である」という荀子の言葉は、教育や学習の大切さを強調したものである。荀子の弟子からは、法家の==韓非==と、秦の始皇帝に仕えた==李斯==が出ている。

:::topic confuse | 孟子と荀子
| | 孟子 | 荀子 |
|---|---|---|
| 人間の本性 | 性善説（生まれつき善の芽生えをもつ） | 性悪説（生まれつき利己的で争う） |
| 重視したもの | 内にある善の芽生えを育てること。王道政治 | 外からの礼による矯正と学習。礼治主義 |
| 政治思想 | 易姓革命の肯定、民本思想 | 礼による秩序。のちの法家思想に影響 |
| 弟子・影響 | のちの宋代の朱子学で重んじられる | 韓非・李斯（法家）を育てる |

「性悪説」は「人間は悪人だ」という意味ではない。放っておけば欲望のままに争ってしまうから、教育と礼が必要だ、という主張である。
:::

## 墨家

==墨子==（前5世紀後半〜前4世紀前半）が開いた==墨家==は、戦国時代の前半には、儒家と並ぶ大きな勢力をもっていた。

墨子は、儒家の説く仁が、家族や身近な者への愛を優先する、差別のある愛（別愛）であると批判した。そして、自分と他人、自分の家族と他人の家族、自分の国と他人の国を区別せずに、すべての人を平等に愛する「==兼愛==」を説いた。また、侵略戦争に反対する「==非攻==」を唱えた。儒家が重んじた豪華な葬式や音楽も、民衆の生活を苦しめる浪費であるとして批判した（節用・節葬）。

墨家は、厳しい規律をもつ集団で、その指導者（鉅子）のもとで、攻められた小国を守るために、城の守りに駆けつけた。墨家は、城壁の防衛の技術にすぐれた、職人や技術者の集団でもあったのである。

:::topic source | 墨子、戦争を止める
楚の王が、名工の公輸盤（こうしゅはん）がつくった雲梯（城攻めの長いはしご）を使って、小国の宋を攻めようとしているという知らせを聞いた墨子は、10日10晩歩き続けて楚の都に駆けつけた。

>> 墨子は帯を解いて城壁に見立て、木の札を攻城の道具に見立てた。公輸盤は、城を攻めるしかけを9回変えて攻めたが、墨子は9回ともこれを防いだ。公輸盤の攻めの道具は尽きたが、墨子の守りには、まだ余裕があった。
-- 出典：『墨子』公輸篇（本サイト訳・抄訳）

机の上の模擬戦で、楚の攻撃が成功しないことを示された楚の王は、宋への攻撃を取りやめたという【伝承】。
:::

墨家は、秦の統一ののち急速に衰え、漢代以降は、ほとんど忘れられた。その思想が再評価されるのは、2000年後の清代末から近代のことである。

## 道家

儒家の説く仁や礼などの道徳を、人為的なものとして批判し、自然のままに生きることを説いたのが、==道家==である。

道家の祖とされる==老子==は、人の作為を捨て、宇宙の根本原理である「道」（タオ）に従って、あるがままに生きる「==無為自然==」を説いた。理想の社会は、人口の少ない小さな国で、人々が素朴に暮らす「小国寡民」の社会であるとした。老子の思想は、『老子』（『道徳経』）にまとめられている。

:::topic debate | 老子は実在したか
『史記』は、老子を、孔子が礼について教えを受けた、周の王室の記録係であったと記している。しかし、司馬遷自身も、老子が誰であったかについて、いくつかの異なる説を併記しており、老子が実在の人物であったかどうかについては、古くから疑問が出されている【諸説】。

1993年、湖北省の郭店（かくてん）にある前300年ごろの楚の墓から、竹の札に書かれた『老子』の一部が見つかった（郭店楚簡）。これは現存する最古の『老子』の写本で、少なくとも戦国時代の中ごろまでには、『老子』のもとになる文章が存在していたことが確かめられた。
:::

!image file="Zhang Lu-Laozi Riding an Ox.jpg" cap="牛に乗る老子（明代の画家張路の作、台北・国立故宮博物院）。老子は、周の衰えを見て西方へ去り、函谷関で関所の役人に請われて『老子』を書き残したと伝えられる。"

戦国時代の==荘子==は、老子の思想を受け継ぎ、善悪・美醜・生死などの区別は、人間の立場から見た相対的なものにすぎず、すべてのものは本来等しいという思想（万物斉同）を説いた。老子と荘子の思想を合わせて「==老荘思想==」という。

:::topic source | 胡蝶の夢
>> 昔、荘周（荘子）は、夢の中で蝶になった。ひらひらと楽しく飛び回る蝶であり、自分が荘周であることなど、分からなかった。ふと目が覚めると、まぎれもなく荘周である。荘周が夢で蝶になったのか、蝶が夢で荘周になったのか、分からない。
-- 出典：『荘子』斉物論篇（本サイト訳）
:::

道家の思想は、のちに、民間の信仰や神仙思想と結びついて、中国の民族宗教である道教の源流の一つとなった。

## 法家

儒家の徳治主義に対して、法と刑罰によって国を治めることを説いたのが、==法家==である。法家の人々は、人間は利益を求めて行動するものだと考え、法を定めて、それに従った者には賞を、背いた者には罰を確実に与える（信賞必罰）ことで、民衆を統制し、君主の権力を強めようとした（==法治主義==）。

前4世紀、秦の孝公に仕えた==商鞅==は、法家の思想に基づく改革を行って、秦を強国に押し上げた（→「春秋・戦国時代」の回）。前3世紀には、荀子に学んだ韓の王族の==韓非==が、法家の思想を集大成し、『==韓非子==』を著した。秦王政（のちの始皇帝）は、『韓非子』を読んで、「この人と会って交わることができれば、死んでも悔いはない」と言ったという。しかし、韓非は、秦に使者として来たのち、同門の李斯の讒言によって、獄中で死に追いやられた【伝承】。

:::topic trivia | 『韓非子』から生まれた故事成語
- 「==矛盾==」：楚の人が、「この盾はどんな矛でも突き通せない」「この矛はどんな盾でも突き通す」と自慢した。ある人が「では、その矛でその盾を突いたらどうなるか」と尋ねると、答えられなかった（難一篇）。韓非は、この話を、儒家が理想の聖人とする堯と舜を同時にほめることの矛盾を突くために用いた。
- 「守株（しゅしゅ）」：宋の農民が、切り株にぶつかって死んだウサギを手に入れた。それからは畑仕事をやめて、切り株を見張り続けたが、ウサギは二度と来なかった（五蠹篇）。昔のやり方にこだわって、時代の変化に対応できない儒家を皮肉った話である。童謡「待ちぼうけ」の題材となった。
:::

兵家の==孫子==（孫武）は、春秋時代の末に呉の王に仕えた兵法家とされる。その兵法書『孫子』は、「戦わずして勝つ」ことを最善とし、戦争を冷静な計算の対象として分析したもので、現代でも、軍事だけでなく、経営などの分野で読まれている。

:::topic now | 2000年ぶりに出てきた『孫子』
かつて、『孫子』の作者については、春秋時代の孫武とする説と、その子孫で戦国時代の斉に仕えた孫臏（そんぴん）とする説があり、決着がついていなかった。1972年、山東省の銀雀山（ぎんじゃくざん）にある前漢の墓から、竹の札に書かれた『孫子』と、それとは別の、孫臏の兵法書が同時に発見された。これによって、『孫子』とは別に、孫臏の兵法書が存在していたことが確かめられた。
:::

## 諸子百家のその後

戦国時代の争いを制した秦は、法家の思想を採用して天下を統一した。秦は、法家以外の思想を厳しく取り締まり、書物を焼き、学者を穴埋めにしたと伝えられる（焚書・坑儒）（→「秦の統一と始皇帝」の回）。

秦に代わった漢では、はじめ道家の思想（黄老思想）が重んじられたが、前漢の武帝の時代に、儒家の思想が国家の正統な学問とされた（→「前漢と武帝」の回）。以後、儒学（儒教）は、2000年以上にわたって、中国の政治と社会の基本的な考え方となり、朝鮮や日本、ベトナムにも大きな影響を与えた。ただし、実際の政治では、表向きは儒家の徳治をかかげながら、法家の法と刑罰による統治も重視された。「外儒内法」（表は儒、内実は法）と呼ばれる。

:::topic works | この時代を描いた作品
- **酒見賢一『墨攻』**（小説、1991年、中島敦記念賞）：墨家の革離が、たった一人で小国の城の守りを任され、大軍の攻撃から城を守る物語。のちに森秀樹によって漫画化され、2006年には香港・中国・日本・韓国の合作で映画化された（アンディ・ラウ主演）。謎の多い墨家の集団と、その防衛技術に光を当てた作品である。
- **井上靖『孔子』**（1989年刊）：孔子の弟子の目から、孔子とその一門の旅を描いた長編小説。
:::

:::summary
- 春秋・戦国時代、富国強兵を求める諸侯のもとで、多くの思想家が活躍した（==諸子百家==）。斉の臨淄には「稷下の学士」が集まった。
- ==儒家==：==孔子==は==仁==と==礼==、==徳治主義==を説き、その言行は『==論語==』にまとめられた。==孟子==は==性善説==と==易姓革命==、==荀子==は==性悪説==と礼による矯正を説いた。
- ==墨家==：==墨子==は==兼愛==と==非攻==を説いた。
- ==道家==：==老子==は==無為自然==、==荘子==は万物斉同を説いた（==老荘思想==）。
- ==法家==：==商鞅==や==韓非==（『==韓非子==』）は、法と賞罰による統治（==法治主義==）を説き、秦に採用された。
- このほか、陰陽家・兵家（==孫子==）・縦横家・名家・農家などがあった。
:::

:::quiz
Q: 人間の本性は善であるとする性善説を説いた思想家はだれか。
+ 孟子
- 荀子
- 韓非
- 墨子
E: 孟子は性善説、荀子は性悪説を説いた。荀子の弟子からは、法家の韓非と李斯が出た。
Q: 墨子が説いた思想として正しいものはどれか。
- 無為自然
+ 兼愛・非攻
- 信賞必罰
- 万物斉同
E: 墨子は、差別のない愛（兼愛）と侵略戦争の否定（非攻）を説いた。無為自然は老子、信賞必罰は法家、万物斉同は荘子の思想である。
Q: 法家の思想を集大成し、秦の始皇帝に高く評価された思想家はだれか。
- 李斯
+ 韓非
- 商鞅
- 孫子
E: 韓非は『韓非子』を著した。李斯は始皇帝の丞相、商鞅は前4世紀の秦の改革者である。
:::
