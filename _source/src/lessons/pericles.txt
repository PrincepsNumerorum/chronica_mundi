ペルシア戦争の後、アテネは、エーゲ海の多くのポリスを従える海の大国となった。その最盛期を指導したのが、将軍==ペリクレス==である。ペリクレスの時代、アテネでは民主政が完成し、パルテノン神殿が建てられ、悲劇や喜劇、哲学が花開いた。

しかし、この時代のアテネには、もう一つの顔があった。同盟国から集めた資金で栄える「帝国」の顔である。そして、その民主政に参加できたのは、アテネの住民のうちのごく一部にすぎなかった。この回では、アテネの民主政が実際にどのように運営されていたのかを、具体的に見ていこう。

## デロス同盟

ペルシア軍はギリシアから撤退したが、いつまた攻めてくるか分からなかった。前478年、アテネを盟主として、エーゲ海の島々や小アジア沿岸のポリスが、ペルシアに備える軍事同盟を結んだ。同盟の本部と金庫は、エーゲ海の中央にあるアポロン神の聖地==デロス島==に置かれた。これを==デロス同盟==という。

加盟したポリスは、船を出すか、その代わりに資金（貢租）を納めることになった。しかし、大きな艦隊を自ら維持できるポリスは少なく、多くのポリスは資金を納める方を選んだ。その資金でアテネが艦隊を建造し、運用したため、同盟の軍事力は事実上アテネの海軍となった。

しだいにアテネは、同盟を自らの支配の道具として使うようになった。同盟からの脱退を図ったナクソスやタソスは、アテネに武力で鎮圧された。前454年には、同盟の金庫がデロス島からアテネに移された。アテネは同盟国の資金を、自国の神殿の建設などにも使うようになり、同盟は「アテネ帝国」と呼ばれるようになる。

:::topic confuse | デロス同盟とペロポネソス同盟
| | ==デロス同盟== | ==ペロポネソス同盟== |
|---|---|---|
| 盟主 | アテネ | スパルタ |
| 成立 | 前478年 | 前6世紀後半 |
| 加盟国 | エーゲ海の島々、小アジア沿岸などのポリス（多くはイオニア人） | ペロポネソス半島のポリス（コリントスなど） |
| 目的 | ペルシアの再来に備える | スパルタを中心とする相互防衛 |
| 特色 | 海軍中心。加盟国は資金を納める。アテネによる支配が強まる | 陸軍中心。加盟国の自立性は比較的高い |
| 政治体制 | アテネは各地で民主政を支援 | スパルタは各地で寡頭政（少数の富裕者による政治）を支援 |
:::

## ペリクレス

ペリクレスは、名門の貴族の家に生まれ、前461年ごろから約30年間、アテネの政治を指導した。彼は、毎年の選挙で選ばれる==将軍（ストラテゴス）==の職に、前443年から15年連続で選ばれ続けた。将軍は、抽選ではなく選挙で選ばれる数少ない役職で、何度でも再選できた。

:::topic source | ペリクレスの葬送演説
ペロポネソス戦争の1年目の冬、ペリクレスは、戦死者を弔う国葬の場で演説を行った。歴史家トゥキディデスが記録した（再構成した）この「葬送演説」は、アテネの民主政の理想を語った言葉として名高い。

>> われらの国制は、他国の法を手本としたものではない。むしろ他国がわれらを手本としている。その名は、少数者ではなく多数者のために治められるがゆえに、民主政と呼ばれる。私的な争いでは、法の前に万人が平等である。公の名誉については、家柄ではなく能力によって選ばれ、貧しくとも、国のためになすべき善きことがあれば、身分の低さによって妨げられることはない。……われらは美を愛するが、贅沢には流れず、知を愛するが、柔弱には陥らない。……要するに、わがアテネは、全ギリシアの学校である。
-- 出典：トゥキディデス『歴史』2巻37〜41節（本サイト訳・抄訳）

美しい理想である。しかし、この演説が語りかけていたのが、成人の男性市民だけであったことも、忘れてはならない。
:::

:::topic trivia | 抽選のための機械
アテネ人は、役人や陪審員を選ぶのに、選挙よりも==抽選==を重んじた。選挙では、弁が立ち、金があり、名の知れた者が選ばれやすい。抽選なら、すべての市民に平等に機会がある。アリストテレスは、「役職を抽選で選ぶのは民主政的であり、選挙で選ぶのは寡頭政的である」と述べている。

前4世紀には、陪審員を公正に選ぶために、「クレーロテーリオン」と呼ばれる石の抽選機が使われた。その実物の一部が、アテネのアゴラから見つかっている。

:::topic life | 赤いロープで民会へ
民会は、成立のために一定の数の出席者が必要な議題もあった。しかし、市民の中には、アゴラで買い物やおしゃべりをして、民会になかなか来ない者もいた。

アリストファネスの喜劇によれば、民会の日には、公共の奴隷であるスキタイ人の弓兵たちが、赤い染料をたっぷり含ませたロープを持ってアゴラを歩き回り、人々を民会の会場の方へ追い立てた。服に赤い染料がついた者は、遅刻した者として罰金を払わされた、あるいは日当をもらえなかったという。
-- 出典：アリストファネス『アカルナイの人々』21〜22行（古注を含む、要旨）
:::

## 民主政に参加できたのは誰か

アテネの民主政は、すべての住民が参加できるものではなかった。

前5世紀後半のアテネの人口は、おおよそ20万〜30万人と推定されている。そのうち、民主政に参加できる成人の男性市民は、3万〜4万人ほどにすぎなかった。残りは、市民の妻や子ども、そして市民権をもたない人々であった。

- **女性**：市民の家の女性であっても、政治には一切参加できなかった。
- **在留外人（==メトイコイ==）**：アテネに住み着いた外国人やその子孫。商工業で活躍し、税と兵役の義務を負ったが、市民権はなく、土地も所有できなかった。
- **==奴隷==**：家事や手工業、農業、ラウレイオン銀山での採掘などで働いた。人口の3分の1ほどを占めたとする推定もある。

さらに前451年、ペリクレスは、両親ともアテネ市民である者だけを市民とする法律を成立させた。市民の特権を守るための措置だったが、これによって、市民になれる者はいっそう限られた。皮肉なことに、のちにペリクレス自身と、外国人の恋人アスパシアとの間に生まれた息子は、この法律のために市民になれず、ペリクレスは民会に特例を願い出なければならなかった。

:::topic confuse | アテネの民主政と現代の民主政
| | アテネの民主政 | 現代の民主政（日本など） |
|---|---|---|
| 形態 | ==直接民主政==（市民が民会に直接参加） | ==間接民主政==（選挙で代表を選ぶ） |
| 役人の選び方 | 主に==抽選== | 主に選挙 |
| 参政権 | 成人男性市民のみ。女性・在留外人・奴隷は除外 | 一定年齢以上のすべての国民（男女） |
| 裁判 | 抽選の市民陪審員による民衆裁判所 | 職業裁判官（日本では裁判員制度もある） |
| 規模 | 市民数万人のポリス | 数百万〜数億人の国家 |

アテネの民主政は、参加者を限ったうえで、その内部では徹底した平等を追求したものだった。参加者を広げつつ、選挙と代表制を用いる現代の民主政とは、考え方の出発点が違うのである。なお、裁判員を抽選で選ぶ日本の裁判員制度（2009年〜）は、抽選で市民を選ぶという点で、アテネの陪審員制度に似ている。
:::

## パルテノン神殿

ペリクレスは、ペルシア軍に焼き払われたアクロポリスの神殿を、壮大な規模で再建した。その中心が、守護女神アテナをまつる==パルテノン神殿==である。前447年に建設が始まり、前432年に完成した。

神殿は、ドーリア式の46本の柱で囲まれ、彫刻家==フェイディアス==の監督のもと、破風や壁面は神話やアテナの祭り（パンアテナイア祭）の行列を描いた見事な彫刻で飾られた。神殿の中には、金と象牙で作られた高さ約12mの巨大なアテナ像が立っていた。

建設の費用の一部には、デロス同盟の資金が使われた。ペリクレスの政敵たちは、「同盟国が戦争のために出した金で、アテネを厚化粧した女のように飾り立てている」と非難したという。

:::topic trivia | まっすぐに見えるための曲線
パルテノン神殿は、まっすぐな直線でできているように見える。しかし実際には、ほとんどの線がわずかに曲がっている。

床（基壇）は、中央が端より約10cm盛り上がっている。柱は、中ほどがわずかにふくらんでおり（エンタシス）、すべてがやや内側に傾いている。柱の内側への傾きを上に延ばしていくと、上空約2kmで一点に集まるという。

これは、まっすぐな線で造ると、目の錯覚で床が中央でたわんで見えたり、柱が細く見えたりするのを補正するための工夫だったと考えられている。奈良の法隆寺の柱のふくらみも、エンタシスの影響だとする説が明治時代に唱えられたが、現在では直接の関係を示す証拠はないとされている【俗説】。
:::

:::topic now | パルテノン神殿の彫刻はどこにあるべきか
パルテノン神殿の彫刻の約半分は、現在、ロンドンの大英博物館にある。19世紀の初め、オスマン帝国の駐在イギリス大使だったエルギン伯爵が、オスマン帝国の許可を得たとして、神殿の彫刻を切り取ってイギリスに運んだものである（「エルギン＝マーブル」）。

ギリシア政府は、彫刻はギリシアの文化遺産の不可分の一部であるとして、長年にわたって返還を求めている。2009年には、アクロポリスのふもとに新しいアクロポリス博物館が開館し、ロンドンにある彫刻の部分を空けて、いつでも返還を受け入れられる展示を用意している。大英博物館は、合法的に取得したものだとして返還を拒んできたが、近年は貸与などの形での協議も報じられている。文化財の返還問題を象徴する事例の一つである。
:::
